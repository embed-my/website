# Accessibility

## Who is responsible for what

Embed My provides the iframe container, a descriptive frame title, and fullscreen support. Inside the frame, the player names the content's frame after the package's own title.

The activity's learning controls, keyboard behavior, captions, alternative text, contrast, and reading order are determined by the H5P content type and by the activity author.

The player's [ACCESSIBILITY.md](https://github.com/missing-elements/h5p-offline-player/blob/main/ACCESSIBILITY.md) describes what the player does and the results of keyboard-only testing across several content types.

## Before publishing

- Give the iframe a meaningful title.
- Complete the activity using only the keyboard.
- Provide captions or transcripts for video and audio.
- Include text alternatives for meaningful images.
- Do not make an H5P interaction the only way to access essential information.
