The player

Every activity on Embed My plays in h5p-offline-player, an open-source H5P player that runs entirely in the browser. It reads the .h5p archive in place through a Service Worker and hands the files to the H5P runtime: nothing is unpacked on a server, and there is no server at all. Embed My is a front for it: the page that writes the snippet, and a frame that runs the player on its own address.

What it does

  • Plays any .h5p package from a URL, or from a file picked on the device, with no upload.
  • Starts a large package after a few kilobytes on a host that answers Range requests, and streams its video.
  • Shows H5P's own toolbar on request: rights of use, download, fullscreen.
  • Emits xAPI statements and the content's saved state as events, for a page or an LMS to collect.
  • Ships as one web component, <h5p-player>, plus a worker; the H5P runtime is a package of its own.

Tools that come with it

  • npx @missing-elements/h5p-verify course.h5p plays a package in a real browser runtime and reports missing libraries, start-up errors and a screenshot, before you share it.
  • npx @missing-elements/h5p-normalize course.h5p rewrites a package once so that its video starts at once instead of after the whole file has downloaded.

Run it yourself

Embed My is the way to use the player with nothing installed. If you would rather have nothing from anyone, put the player on your own site: it is three files and a line of HTML, and the setup guide covers each way to do it. Your packages stay as they are. The player origin of Embed My is a small example of exactly that.
